# Тренажер для підготовки до тестів та іспитів (Trainer 2026)

Цей проєкт є курсовою роботою з дисципліни «Основи програмування». Програма дозволяє створювати набори запитань, проводити тренувальні сесії та аналізувати результати навчання через інтерфейс командного рядка (CLI).

## 1. Призначення програми
Програма розроблена для автоматизації процесу підготовки до іспитів. Вона дозволяє користувачам:
* Створювати власну базу запитань за темами.
* Проходити тестування у випадковому або ручному режимі.
* Переглядати статистику успішності та історію проходжень.
* Аналізувати помилки після завершення тесту.

## 2. Предметна область
Об'єктом моделювання є навчальний процес. Основні сутності:
* **Тема (Topic):** Контейнер для запитань певної дисципліни.
* **Запитання (Question):** Базова одиниця тесту (підтримуються Single Choice, Multiple Choice, Open Ended).
* **Результат (TestResult):** Дані про пройдену сесію (бал, дата, тема).
* **Конфігурація (AppConfig):** Налаштування системи (бали, режими відображення).

## 3. Функціональні можливості
* **CRUD операції:** Створення, редагування та видалення тем і запитань.
* **Підтримка типів:** Тести з однією відповіддю, кількома відповідями та текстовим вводом.
* **Гнучкі сесії:** Вибір кількості питань або вибір конкретних питань вручну.
* **Рандомізація:** Перемішування порядку питань та варіантів відповідей (згідно з варіантом 3).
* **Аналітика:** Розрахунок середнього балу за темами та перегляд історії.
* **Корекція:** Перегляд списку помилок після завершення тесту.

## 4. Архітектура рішення
Проєкт побудований за багатошаровою архітектурою (N-Tier):
* **Trainer.Domain:** Моделі даних та базова логіка перевірки відповідей.
* **Trainer.DataAccess:** Робота з файловою системою, реалізація Generic Repository для JSON-серіалізації.
* **Trainer.BusinessLogic:** Сервіси для генерації сесій, підрахунку результатів та обробки статистики.
* **Trainer.UI:** Інтерфейс командного рядка (CLI) з розподілом логіки на Handlers.

## 5. Технології
* **Платформа:** .NET 10.0
* **Мова:** C# 13
* **Формат даних:** JSON (System.Text.Json)
* **Тестування:** NUnit (26 тестів)

## 6. Інструкція зі збирання та запуску

### Системні вимоги:
* Встановлений .NET 10.0 SDK.

### Збирання проєкту:
```bash
dotnet build -c Release

Запуск програми:

Перейдіть до папки UI-проєкту та запустіть його:
code Bash

cd src/Trainer.UI
dotnet run

Публікація в один файл (Publish):
code Bash

dotnet publish -r win-x64 -c Release --self-contained true -p:PublishSingleFile=true

7. Робота з програмою (CLI команди)

    list — переглянути всі теми.

    start <Topic> — почати тест (запитає про кількість питань або ручний вибір).

    create-topic — створити тему.

    add-question <Topic> — додати нове питання.

    edit-topic <Topic> — змінити назву теми.

    delete-topic <Topic> — видалити тему.

    stats — переглянути середні бали.

    history — переглянути журнал результатів.

    settings — змінити налаштування програми.

    help — повний список команд.

8. Дані

Дані зберігаються у форматі JSON у папці ./data/ поруч із виконуваним файлом.

    topics.json — база питань.

    history.json — журнал результатів.

    settings.json — налаштування.

9. Тестування

Для запуску Unit-тестів виконайте:
code Bash

dotnet test
