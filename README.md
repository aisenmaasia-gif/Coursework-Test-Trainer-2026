TestSimulator

Система для генерації, проходження та аналітики тестувань, розроблена в рамках курсового проєкту. Додаток побудований за принципами багатошарової архітектури (N-Tier) та орієнтований на детальну роботу зі структурами даних завдяки явним, низькорівневим реалізаціям алгоритмів обробки замість надлишкових абстракцій фреймворку.
🏗 Архітектура проєкту

Рішення розділене на незалежні збірки для забезпечення слабкої зв'язності (Loose Coupling) та чіткого розподілу відповідальності:

    TestSimulator.Domain: Ядро системи. Містить доменні моделі (Question, Test, TestSession, TestResult), перерахування (DifficultyLevel, QuestionType), кастомні винятки (TestSimulatorException) та методи розширення.

    TestSimulator.DAL: Шар доступу до даних. Реалізує ITestRepository для роботи з файловою системою (JsonTestRepository), забезпечуючи транзакційне збереження конфігурацій, тем та результатів у форматі JSON.

    TestSimulator.BLL: Шар бізнес-логіки. Включає TestService для управління життєвим циклом тестування та AnalyticsService для обробки результатів і збору поглибленої статистики.

    TestSimulator.Tests: Модульні тести на базі NUnit, що покривають критичну бізнес-логіку та аналітичні сервіси.

    UI (В розробці / Окрема збірка): Інтерфейс користувача для взаємодії з API бізнес-логіки.

✨ Основний функціонал

    Гнучка система питань: Підтримка одиночного вибору (Single Choice), множинного вибору (Multiple Choice) та відкритих відповідей (Open Answer).

    Управління сесіями: Динамічне збереження прогресу, трекінг відповідей та об'єктивний підрахунок балів (QuestionScore).

    Власна аналітика: Збір та агрегація статистики по пройдених тестах з використанням класичних структур даних та об'єктно-орієнтованого підходу.

    Локальна база даних: Автономне збереження інформації у директорії Data (config.json, results.json, topics.json).

💻 Стек технологій

    Платформа: .NET 10.0, C#

    Архітектура: N-Tier, OOP

    Тестування: NUnit

    Зберігання даних: JSON

    Середовище: Оптимізовано для розробки у Visual Studio Code без прив'язки до AI-генераторів коду.

🚀 Встановлення та запуск

    Склонуйте репозиторій:
    Bash

    git clone <URL_репозиторію>

    Перейдіть у кореневу директорію курсової роботи:
    Bash

    cd "Course work/courseWork"

    Відновіть залежності та побудуйте рішення:
    Bash

    dotnet build

    Запустіть модульні тести для перевірки цілісності BLL:
    Bash

    dotnet test TestSimulator.Tests/TestSimulator.Tests.csproj

    Запустіть основний застосунок:
    Bash

    dotnet run --project TestSimulator/TestSimulator.csproj
